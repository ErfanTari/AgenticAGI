# Control Scheme for 3D Tennis Game

This document outlines the planned control scheme for the 3D Tennis Game, based on the core mechanics and game design principles.

## Player Controls

### Movement
-   **W**: Move Forward
-   **A**: Move Left
-   **S**: Move Backward
-   **D**: Move Right

### Shot Types
-   **Spacebar**: Upper Hand Shot (e.g., powerful serve, smash)
-   **U Key**: Middle Hand Shot (e.g., standard forehand/backhand)
-   **I Key**: Backhand Shot (e.g., slice, defensive shot)
-   **O Key**: (To be determined) Potentially for a special shot, serve type, or other advanced action.
