# Neolith Catalog Download Procedure

# Neolith General Catalog Download

## Steps:
1. Navigate to the Neolith official website.
2. Locate the 'Products' or 'Catalogs' section in the navigation menu.
3. Find the link for the 'General Catalog'.
4. Click the download button/link to save the file.
5. Save the downloaded catalog file into a designated folder within your workspace directory.
