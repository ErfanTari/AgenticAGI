# Fibonacci Function Implementation

Implementation: Uses array-based approach for clarity. Returns nth Fibonacci number where fib(1)=1, fib(2)=1, fib(n)=fib(n-1)+fib(n-2). Test cases verified: fibonacci(1)=1, fibonacci(5)=5, fibonacci(10)=55.
