# Download Neolith Catalog

# Steps to Download Neolith General Catalog

1. Visit the Neolith official website.
2. Navigate to the 'Products' or 'Catalogs' section.
3. Locate the 'General Catalog'.
4. Click on the download link for the catalog.
5. Save the file to your preferred location.
