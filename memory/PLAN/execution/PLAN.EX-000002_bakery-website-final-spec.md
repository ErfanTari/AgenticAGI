# bakery-website-final-spec

## Artisan Bakery Website - "The Golden Crust"

A polished, visually distinctive single-page website for an artisan neighborhood bakery.

### Design Language
- Color palette: Warm cream (#FFF8F0), deep brown (#3C2415), golden amber (#D4A574), sage green (#7A8B6E), terracotta (#C67B5C)
- Typography: Google Fonts - Playfair Display (headings), Lora (body), Cormorant Garamond (accents)
- Style: Rustic elegance with subtle textures, soft shadows, organic shapes
- Layout: Full-width hero, card-based sections, smooth scroll navigation

### Sections
1. **Navigation** - Fixed top nav with logo, links (Home, About, Menu, Gallery, Contact), mobile hamburger menu
2. **Hero** - Full-viewport hero with gradient overlay, bakery name tagline, CTA button, decorative wheat/flower SVG elements
3. **About** - Two-column layout with story text and decorative elements, values icons
4. **Menu** - Grid of product cards (bread, pastries, cakes, seasonal items) with prices, descriptions, hover effects
5. **Specialties** - Featured items with larger cards and highlight badges
6. **Testimonials** - Customer reviews carousel with quotes and ratings
7. **Gallery** - CSS grid photo gallery with hover zoom effects
8. **Visit Us** - Hours, address, map placeholder, contact info
9. **Newsletter** - Email signup form
10. **Footer** - Social links, copyright, quick links

### Interactive Features
- Smooth scroll navigation
- Mobile responsive hamburger menu
- Scroll-triggered fade-in animations
- Menu card hover effects
- Testimonial auto-rotating carousel
- Newsletter form with validation
- Back-to-top button
- Parallax-like hero effect

### Technical
- All CSS inline in <style> tag
- All JS inline in <script> tag
- Google Fonts via CDN
- No external dependencies beyond fonts
- Responsive design (mobile-first)
- Semantic HTML5
- CSS custom properties for theming
