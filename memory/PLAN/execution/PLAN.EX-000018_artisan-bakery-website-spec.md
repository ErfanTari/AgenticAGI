# Artisan Bakery Website Spec

Create a polished, visually distinctive single-file HTML website for an artisan neighborhood bakery. Include:

1. HERO SECTION: Warm rustic header with bakery name "The Rustic Crumb", tagline "Handcrafted Bread & Pastries Since 1985", navigation menu (Home, Products, About, Contact), hero image placeholder with warm lighting effect

2. PRODUCTS SECTION: Grid display of featured items (Sourdough, Croissants, Artisan Breads, Seasonal Pastries) with prices, descriptions, and "Order Now" buttons

3. ABOUT SECTION: Story about the bakery's heritage, artisan baking methods, locally sourced ingredients

4. CONTACT SECTION: Address, phone, hours, email, simple contact form with validation

5. VISUAL DESIGN: Warm color palette (golden browns, cream whites, deep reds), serif fonts for headings, clean sans-serif for body text, subtle animations on hover, responsive layout for mobile/desktop

6. TECHNICAL REQUIREMENTS: All CSS and JavaScript must be inline within a single index.html file. No external dependencies. Include smooth scroll navigation, form validation with error messages, mobile hamburger menu, and subtle page transitions.
