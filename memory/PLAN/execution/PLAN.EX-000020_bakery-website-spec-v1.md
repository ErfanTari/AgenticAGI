# bakery-website-spec-v1

## Artisan Neighborhood Bakery Website - "The Golden Crumb"

### Overview
A warm, inviting single-page website for an artisan bakery that emphasizes quality ingredients, traditional techniques, and community connection. The design should feel rustic yet modern, with a focus on visual appeal of baked goods.

### Visual Design
- **Color Palette**: Warm earth tones - #8B4513 (saddle brown), #D2691E (chocolate), #F5DEB3 (wheat), #FFF8DC (cream), #CD853F (peru)
- **Typography**: Serif headings (Georgia/Courier fallback), clean sans-serif body text
- **Layout**: Full-width hero section, grid-based product showcase, parallax scrolling effects

### Sections Required
1. **Hero Section**: Large bakery storefront image with warm overlay, welcoming headline "Fresh Bread, Made Daily"
2. **About Us": Story of family-owned tradition, emphasis on quality ingredients
3. **Featured Products**: Grid display of signature items (sourdough, croissants, pastries) with prices
4. **Daily Specials**: Rotating carousel of daily offerings
5. **Testimonials**: Customer reviews in styled cards
6. **Location & Hours**: Map placeholder, address, opening hours table
7. **Newsletter Signup**: Simple form for updates

### Interactive Elements
- Smooth scroll navigation with active section highlighting
- Hover effects on product cards (lift + shadow)
- Image parallax scrolling effect
- Mobile-responsive design with hamburger menu
- Newsletter form validation and submission animation

### Technical Requirements
- Single self-contained HTML file with inline CSS and JavaScript
- No external dependencies except Google Fonts (load via CDN)
- Semantic HTML5 structure
- CSS Grid and Flexbox for layout
- Vanilla JavaScript for interactions (no frameworks)
- Accessible navigation with ARIA labels
