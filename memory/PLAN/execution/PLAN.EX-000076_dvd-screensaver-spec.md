# DVD Screensaver Spec

## DVD Screensaver Specification

Create an HTML file with:
1. Nostalgic DVD-style logo text that bounces around the screen
2. Corner detection that triggers a visual effect every 120 seconds
3. Classic DVD logo colors (silver/gray with rainbow text effect)
4. Smooth bouncing animation with velocity changes on corner hits
5. Timer display showing time until next corner hit

Technical requirements:
- Use HTML5 Canvas or DOM elements for the logo
- Implement collision detection with screen boundaries
- Track time since last corner hit (120 second interval)
- Visual feedback when hitting corners (color flash or animation)
- Responsive design that works on different screen sizes
