# Price Dashboard Spec

## Price Dashboard Website Specification

Create a single HTML file with inline CSS and JavaScript that:
1. Fetches live prices from free APIs (no API key required)
2. Displays currency exchange rates (USD to major currencies)
3. Displays cryptocurrency prices (BTC, ETH, etc.)
4. Displays gold and silver spot prices
5. Auto-refreshes every 60 seconds
6. Clean modern UI with cards for each asset type
