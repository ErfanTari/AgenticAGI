# YouTube Homepage Spec

## YouTube Homepage Specification

Create a single self-contained HTML file named youtube.html with:

1. **Header**: Red YouTube logo, search bar with search button, user icons (create, notifications, profile)
2. **Sidebar**: Collapsible navigation with Home, Trending, Subscriptions, Library sections
3. **Main Content**: Video grid with thumbnail images, video titles, channel names, view counts, and upload times
4. **Styling**: Use YouTube's color scheme (red #FF0000, white, dark grays), responsive grid layout, hover effects on video thumbnails
5. **Interactivity**: Sidebar toggle button, search bar focus states, responsive design for mobile/tablet/desktop
