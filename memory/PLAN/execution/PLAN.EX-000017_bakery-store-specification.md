# Bakery Store Specification

Create a single-file HTML bakery store. Features: 1) Header with logo and navigation, 2) Hero section with welcome message, 3) Product grid displaying at least 6 items (cakes, pastries, breads) with images, prices, and 'Add to Cart' buttons, 4) Shopping cart modal/sidebar showing selected items, total price, and checkout button, 5) Responsive design using CSS Grid/Flexbox, 6) JavaScript for cart logic (add/remove/update quantities, calculate totals). Use placeholder images from unsplash.com.
