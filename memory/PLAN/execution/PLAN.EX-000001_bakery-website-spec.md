# bakery-website-spec

## Artisan Bakery Website Specification

### Visual Design & Layout
- **Color Palette**: Warm artisan tones - #5D4037 (dark brown), #8D6E6B (medium brown), #F5F1E6 (cream background), #D4A373 (golden accent)
- **Typography**: Serif fonts for headings (Georgia, serif), clean sans-serif for body text
- **Layout**: Single-page responsive design with smooth scrolling navigation
- **Hero Section**: Large welcoming banner with bakery name 'The Golden Crumb' and artisan tagline
- **Navigation**: Sticky header with links to Home, Menu, About, Testimonials, Contact

### Sections & Features
1. **Hero Section**: Full-width banner with bakery name, tagline 'Artisan Bread & Pastries', call-to-action button
2. **Menu/Product Showcase**: Grid of 6-8 featured items with images, descriptions, prices, and 'Add to Cart' buttons
3. **About Section**: Story of the bakery - family-owned, traditional methods, local ingredients
4. **Testimonials**: 3-4 customer reviews with star ratings
5. **Contact Section**: Simple contact form (name, email, message) and bakery info (address, hours, phone)

### Interactive Elements
- **Shopping Cart**: JavaScript-based cart system with item counter, total calculation, and checkout simulation
- **Smooth Scrolling Navigation**: Click navigation links to scroll smoothly to sections
- **Mobile Responsive**: All layouts adapt to tablet and mobile screens
- **Hover Effects**: Subtle animations on buttons and product cards

### Technical Requirements
- Single self-contained HTML file with inline <style> and <script> tags
- No external dependencies - all CSS/JS embedded
- Responsive design with @media queries
- Semantic HTML5 structure
- Accessibility considerations (alt text, proper contrast)
