# React TypeScript Starter Project Setup

- Create project root directory
- Add `src/` folder containing:
  - `components/`
  - `App.tsx`
  - `index.html`
- Add `public/` folder for static assets
- Create `README.md` in root with project description
- Generate basic `package.json` with dependencies
- Write simple App.tsx component that renders 'Hello World'
